# docker refresh

Маленькое Flask-приложение: `/` считает визиты и пишет счётчик в файл, `/health` для проверки.

Настройки через переменные окружения:
- `PORT` — порт (по умолчанию 5000)
- `GREETING` — приветствие (по умолчанию `hello`)
- `DATA_DIR` — куда писать счётчик (по умолчанию `/data`)

Локально без докера: `pip install -r requirements.txt && python app.py`

## Задачи

1. Напиши `Dockerfile`, собери образ с тегом (не `latest`), запусти, `curl localhost:<порт>/`.
2. Запусти с `-e GREETING=privet` и на другом порту (`PORT` + `-p`).
3. Перезапусти контейнер — счётчик сбросился? Сделай так, чтобы не сбрасывался (volume).
4. Добавь `.dockerignore`. Проверь, что смена `app.py` не переустанавливает зависимости при сборке (кеш слоёв).
5. Запусти не от root.
6. Добавь `HEALTHCHECK` на `/health`, посмотри статус в `docker ps`.
7. Запушь образ в Docker Hub или GHCR.
8. (бонус) Замени `python app.py` на gunicorn.

Ответь себе письменно ниже: чем отличаются `CMD` и `ENTRYPOINT`, `EXPOSE` и `-p`, `COPY` и `ADD`.

## Заметки
CMD это в конце запуск самого процеса приложения
ENTRYPOINT это как CMD только в него можно аргументы передавтаь при докер ран сразу без флагов
EXPOSE это какой докер порт ждет от приложения
-p это то что мы открваем
COPY копирования файлов с дириктории в контейнер. предсказуемая
ADD много всего можно ей делать, в том числе функционал copy. непредсказуемая
